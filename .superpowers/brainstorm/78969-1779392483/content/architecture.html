Workstream 1: R2 Storage (fix/phase-4-storage)

Cloudflare R2

Replace Vercel Blob entirely. Files get permanent public URLs — no signed URL expiry, no proxy.

New flow

  • Upload → R2 bucket → save public URL to DB
  • Playback → direct public URL in <audio> tag
  • Download → 302 redirect to public URL
  • Zero egress cost, free CDN
